# ReLoop — Second-Hand Product Marketplace

Files:
- index.html: Website structure
- style.css: Styling, responsive layout, and 3D hover effects
- script.js: Search, category filters, sorting, favourites, and demo listing form

Run: Keep all files in the same folder and open index.html in a browser, or use VS Code Live Server.

Note: This is a frontend demo. New listings are held in browser memory and reset when refreshed. Persistent listings, login, messaging, and payments need a backend/database.
